# DCF valuation memo decks

PowerPoint DCF memos generated by `tools/builders/build_dcf_memo.py`, driven
entirely by a real, recalculated instance workbook. Unlike the other domains'
memo decks, the default instance (`public_adobe_dcf_proxy`) is an
agent-tool-drafted instance from `tools/agents/dcf_comps.py
--use-adobe-dcf-fixture`, not a registered `standards/public_cases/index.json`
case -- its manifest lives at
`01_Investment_Banking/instances/public_adobe_dcf_proxy.manifest.json`, tagged
`classification: "agent_tool_draft"`, `counts_toward_M4: false`. This deck
demonstrates the full governed pipeline end to end: agent tool drafts a
provenance-checked instance -> real LibreOffice recalculation -> PowerPoint
memo, all reading the same governed artifacts, none of them invented.

## Regenerating

```bash
pip install -r requirements.txt   # python-pptx
PYTHONPATH=. python tools/agents/dcf_comps.py --use-adobe-dcf-fixture
python tools/builders/build_dcf_memo.py --instance-slug public_adobe_dcf_proxy
```

## Verification

`tests/test_build_dcf_memo.py` independently re-recalculates the source
workbook and asserts the base-revenue seed, WACC/terminal-growth routing, and
implied value/share all match the workbook exactly -- including regression
coverage for the two real disconnected-cell bugs this pipeline caught during
development (see tools/agents/dcf_comps.py's module docstring).
