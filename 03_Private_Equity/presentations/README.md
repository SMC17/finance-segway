# IC memo decks

PowerPoint IC memos generated by `tools/builders/build_ic_memo.py`, driven entirely
by a real, recalculated instance workbook plus its governed manifest
(`standards/public_cases/<case_id>.json`). Nothing on these slides is invented
independent of the model: every figure is either read from the recalculated
workbook or explicitly labeled illustrative, using the same `observed` /
`derived` / `modeler_assumption` provenance convention as the Excel evidence
registries.

## Regenerating

```bash
pip install -r requirements.txt   # python-pptx
python tools/builders/build_ic_memo.py --case-id pe-public-home-depot-2023
```

## Verification

`tests/test_build_ic_memo.py` independently re-recalculates the source
workbook (not by re-reading the builder's own variables) and asserts every
headline figure, table total, and sensitivity-grid cell on the deck matches
it exactly, and that every source name on the deck traces to the manifest's
own `sources` list. Run it like any other test:

```bash
PYTHONPATH=. python -m unittest tests.test_build_ic_memo
```

## Why Home Depot, and what "illustrative" means here

Home Depot has never been the subject of a real leveraged buyout. This deck
(and its underlying instance, `03_Private_Equity/instances/public_home_depot_2023.xlsx`)
uses Home Depot's real, SEC-sourced FY2023 revenue, EBITDA margin, and revenue
growth as the operating base for a pedagogical LBO exercise — the entry/exit
multiple, capital structure, and debt terms are template defaults, not real
deal terms. The deck says this explicitly on its second slide and tags every
illustrative figure individually; it does not just disclose the limitation
once and then present illustrative numbers as if they were real.
