# Operating memo decks

PowerPoint operating memos generated by `tools/builders/build_software_memo.py`,
driven entirely by a real, recalculated instance workbook plus its governed
manifest (`standards/public_cases/<case_id>.json`). Nothing on these slides is
invented independent of the model: every figure is either read from the
recalculated workbook or explicitly labeled illustrative, using the same
`observed` / `derived` / `modeler_assumption` provenance convention as the
Excel evidence registries.

## Regenerating

```bash
pip install -r requirements.txt   # python-pptx
python tools/builders/build_software_memo.py --case-id software-public-uipath-fy2023-stress
```

## Verification

`tests/test_build_software_memo.py` independently re-recalculates the source
workbook and asserts the real, disclosed Beginning/Ending ARR and net
retention figures match the workbook exactly, and that the deck's realized
outcome matches the case's own manifest.
