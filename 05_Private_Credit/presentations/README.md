# Credit memo decks

PowerPoint credit memos generated by `tools/builders/build_credit_memo.py`,
driven entirely by a real, recalculated instance workbook plus its governed
manifest (`standards/public_cases/<case_id>.json`). Nothing on these slides
is invented independent of the model: every figure is either read from the
recalculated workbook or explicitly labeled illustrative, using the same
`observed` / `derived` / `modeler_assumption` provenance convention as the
Excel evidence registries. This is the second domain on the IC-memo/pptx
system (after `03_Private_Equity`), proving `tools/builders/pptx_helpers.py`
generalizes past the LBO/PE flagship.

## Regenerating

```bash
pip install -r requirements.txt   # python-pptx
python tools/builders/build_credit_memo.py --case-id credit-public-ares-2024
```

## Verification

`tests/test_build_credit_memo.py` independently re-recalculates the source
workbook (not by re-reading the builder's own variables) and asserts every
headline figure, the covenant-headroom line-chart series (read back from the
native pptx chart's own cached values), and the recovery bridge on the deck
match it exactly, plus that every source name cited on the deck traces to
the manifest's own `sources` list. Run it like any other test:

```bash
PYTHONPATH=. python -m unittest tests.test_build_credit_memo
```

## Why Ares Capital, and what "illustrative" means here

Only the five largest borrower/segment portfolio fair values
(`Portfolio & Concentration!C5:C9`) are real, SEC-sourced inputs on this
instance, from Ares Capital's FY2024 Form 10-K — Ares Capital's real
disclosed exposure. Every other figure on the deck (per-borrower leverage,
covenant thresholds, yield/spread pricing, and the recovery bridge) is a
template default applied to that real exposure, not Ares Capital's actual
underwriting, pricing, or covenant package on any of these positions. The
deck says this explicitly on its second slide and tags every illustrative
figure individually.
