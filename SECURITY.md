# Security policy

Report vulnerabilities privately through [GitHub security advisories](https://github.com/SMC17/finance-segway/security/advisories/new), not in a public issue.

Include the commit, the toolchain, and the smallest input that triggers the problem. This project has one maintainer; expect an acknowledgement within 7 days and a plan within 30. Fixes are credited in the release notes unless you ask otherwise.

Only the latest release and `main` receive fixes.
