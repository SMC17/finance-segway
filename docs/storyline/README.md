# Storyline visuals

Annotated time-series charts for public historical cases. Knight Lab
[StorylineJS](https://storyline.knightlab.com/) contract (CSV + cards, max 12),
rendered here as a self-contained HTML file so a clone works without Google
Sheets, Excel, or a Bloomberg terminal.

This is a **view** of hashed evidence, not a new modeling domain and not an M4
instance.
