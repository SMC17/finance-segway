# Fund memo decks

PowerPoint fund memos generated by `tools/builders/build_etf_memo.py`, driven
entirely by a real, recalculated instance workbook plus its governed manifest
(`standards/public_cases/<case_id>.json`). Nothing on these slides is invented
independent of the model: every figure is either read from the recalculated
workbook or explicitly labeled illustrative, using the same `observed` /
`derived` / `modeler_assumption` provenance convention as the Excel evidence
registries.

## Regenerating

```bash
pip install -r requirements.txt   # python-pptx
python tools/builders/build_etf_memo.py --case-id etf-public-kweb-2026-stress
```

## Verification

`tests/test_build_etf_memo.py` independently re-recalculates the source
workbook and asserts every headline figure on the deck matches it exactly --
including that the sector table's real 102.6% total (not smoothed to 100%)
appears verbatim, and that the fund's real 5-year average annual total return
matches the case's own manifest.
